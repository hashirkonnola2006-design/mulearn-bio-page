# Hashir | Personal Biography & Portfolio

A modern, responsive personal biography and portfolio web page built with semantic HTML5 and vanilla CSS (no external CSS frameworks or dependencies).

Live Preview: [https://hashirkonnola2006-design.github.io/mulearn-bio-page/](https://hashirkonnola2006-design.github.io/mulearn-bio-page/)

---

## 🚀 Features

- **Hero Section**: Circular avatar with an animated rotating gradient ring, live status badge with pulse animation, name, title tagline, and direct CTA buttons.
- **About Me**: Narrative bio introducing background at College of Engineering Thalassery (KTU), freelance journey, tech leadership, career aspirations (Anthropic/AI systems), and milestone highlight metrics.
- **Skills & Technologies**: Responsive flexbox wrapped badges/pills grouped by Frontend, Backend & Databases, and Tools & Workflow with hover glow interactions.
- **Journey & Timeline**: Vertical timeline layout highlighting roles as MuLearn Tech Lead, freelance projects (*Al-Mandi Royal*, wedding platform), and B.Tech in CS.
- **Social Links**: Clean icon buttons with embedded SVGs linking to GitHub, LinkedIn, Twitter/X, and Email.
- **Contact & Footer**: Actionable CTA card with a `mailto:` link, downloadable resume button, back-to-top shortcut, and copyright.
- **Responsive & Accessible**: Media query breakpoints for tablets (`768px`) and mobile screens (`480px`).

---

## 🛠️ Tech Stack

- **HTML5**: Semantic tags (`<header>`, `<main>`, `<section>`, `<footer>`, `<nav>`).
- **CSS3**: Vanilla CSS using CSS Variables (`:root`), Flexbox, CSS Grid, animations, and glassmorphism (`backdrop-filter`).
- **Typography**: Google Font (*Outfit*) for sleek modern titles and system font stack for readable body text.

## 💻 Getting Started Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/hashirkonnola2006-design/mulearn-bio-page.git
   cd mulearn-bio-page
   ```

2. **Open in browser:**
   - Double-click `index.html` to open it directly in your browser.
   - Or serve with any static server:
     ```bash
     npx serve .
     ```
